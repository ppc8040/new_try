# Flask Dashboard with SharePoint Integration

This project is a web-based dashboard built with Flask that integrates with Microsoft Graph API to fetch and display Excel data from SharePoint. User authentication is implemented using Flask-Login, and the tables are dynamically filtered based on the logged-in user's data.

## 📋 Features
- User authentication with Flask-Login
- Secure access to SharePoint data using Microsoft Graph API
- Dynamic tables with search functionality
- Filtered Excel data displayed per user
